# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-06-24

### Added
- ✨ Single-method actions now **replace** the existing method in place instead of inserting a duplicate — regenerating `copyWith`, `toJson`, `fromJson`, or `toString` on a class that already has it will update the implementation cleanly

### Fixed
- 🐛 `toString()` now calls `.toString()` explicitly on custom-class properties (e.g. `${address.toString()}`) instead of relying on implicit string interpolation

---

## [1.1.0] - 2026-06-20

### Added
- ✨ Duplicate method detection — generating a method that already exists in the class now shows a warning and skips it instead of inserting a duplicate
- ✨ Barrel file action now available in the IDE Project View (right-click on a directory node), not only via file context menus
- ✨ Barrel file action registered in the "New" group for easier discovery

### Fixed
- 🐛 Barrel file generator no longer includes itself in its own exports
- 🐛 `DartClassParser` now strips method bodies before scanning for properties, preventing return types inside method blocks from being mistakenly parsed as class fields
- 🐛 Barrel file header updated to "Generated by Dart Data Toolkit" (was incorrectly "Dart Data Class Generator")

---

## [1.0.0] - 2026-06-18

### Added
- ✨ Dart method generator (copyWith, toJson, fromJson, toString)
- ✨ Barrel file generator (index.dart with 3 styles)
- 🎨 Interactive dialog to choose methods
- 🎨 Configurable dialog for barrel files
- 📚 Complete documentation
- 🧪 Working examples
- ⌨️ Keyboard shortcuts (Ctrl+Alt+D, Ctrl+Alt+J, Ctrl+Alt+B on Windows/Linux; Cmd+Alt+D, Cmd+Alt+J, Cmd+Alt+B on macOS)
- ✅ Nullable type support
- ✅ Recursive directory support
- 🏗️ Nested JSON object support in JSON-to-Dart generator — each nested object generates a separate Dart class
- ✅ `toJson()` calls `.toJson()` on custom class properties (nested objects)
- ✅ `fromJson()` calls `ClassName.fromJson(json['key'] as Map<String, dynamic>)` on custom class properties
