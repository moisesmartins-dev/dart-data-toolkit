# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
e este projeto segue [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.3.0] - 2026-10-28

### Added
- ✨ Nova inspeção **"copyWith() is missing class fields"** (warning): avisa quando um `copyWith` não tem parâmetro para um ou mais campos da classe, com o quick fix **Generate copyWith** (Alt+Enter) que regenera o método no lugar. Requer o plugin Dart; sem ele, o restante do plugin funciona normalmente

### Changed
- 🔧 O cabeçalho do barrel file agora usa `//` em vez de `///`. Barrel files gerados por versões anteriores (`///`) continuam sendo reconhecidos e excluídos dos exports
- 🔧 Gerar um barrel file não exibe mais o diálogo de sucesso; erros continuam sendo informados
- 🔧 Compatível com builds 233 até 262 da plataforma IntelliJ (IntelliJ IDEA 2026.2 e Android Studio baseados nela)
- 🔧 A geração de `copyWith` não inclui mais campos `static` nem privados (`_name`), que não podiam ser usados como parâmetros nomeados
- 🔧 `gradlew` substituído pelo Gradle Wrapper padrão (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`) fixado no Gradle 8.14.4; o script anterior apontava para um caminho do Gradle 8.8 específico de uma máquina
- 🔧 Ferramentas de build: IntelliJ Platform Gradle Plugin 2.10.5, Kotlin 2.4.21, compilado contra o IntelliJ IDEA 2026.2.3, Gradle 8.14.4 no CI

### Fixed
- 🐛 Campos `static final` / `static const` não são mais interpretados como propriedades de instância

---

## [1.2.0] - 2026-06-24

### Added
- ✨ Ações individuais de método agora **substituem** o método existente no lugar, em vez de inserir um duplicado — regenerar `copyWith`, `toJson`, `fromJson` ou `toString` em uma classe que já possui o método atualiza a implementação de forma limpa

### Fixed
- 🐛 `toString()` agora chama `.toString()` explicitamente em propriedades de classes customizadas (ex: `${address.toString()}`) em vez de depender da interpolação implícita de string

---

## [1.1.0] - 2026-06-20

### Added
- ✨ Detecção de métodos duplicados — gerar um método que já existe na classe agora exibe um aviso e pula a geração em vez de inserir um duplicado
- ✨ Ação de barrel file disponível na Project View do IDE (clique direito em um diretório), não apenas via menu de contexto de arquivo
- ✨ Ação de barrel file registrada no grupo "New" para facilitar o acesso

### Fixed
- 🐛 Gerador de barrel file não inclui mais a si mesmo nas próprias exportações
- 🐛 `DartClassParser` agora remove os corpos de métodos antes de escanear propriedades, evitando que tipos de retorno dentro de métodos sejam interpretados erroneamente como campos da classe
- 🐛 Comentário de cabeçalho do barrel file corrigido para "Generated by Dart Data Toolkit" (estava incorretamente como "Dart Data Class Generator")

---

## [1.0.0] - 2026-06-18

### Added
- ✨ Gerador de métodos Dart (copyWith, toJson, fromJson, toString)
- ✨ Gerador de barrel files (index.dart com 3 estilos)
- 🎨 Dialog interativo para escolher métodos
- 🎨 Dialog configurável para barrel files
- 📚 Documentação completa
- 🧪 Exemplos funcionando
- ⌨️ Atalhos de teclado (Ctrl+Alt+D, Ctrl+Alt+J, Ctrl+Alt+B no Windows/Linux; Cmd+Alt+D, Cmd+Alt+J, Cmd+Alt+B no macOS)
- ✅ Suporte a tipos anuláveis
- ✅ Suporte a diretórios recursivos
- 🏗️ Suporte a objetos JSON aninhados no gerador JSON-to-Dart — cada objeto aninhado gera uma classe Dart separada
- ✅ `toJson()` chama `.toJson()` em propriedades de classes customizadas (objetos aninhados)
- ✅ `fromJson()` chama `NomeClasse.fromJson(json['key'] as Map<String, dynamic>)` em propriedades de classes customizadas
